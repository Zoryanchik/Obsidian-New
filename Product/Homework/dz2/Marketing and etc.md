### 1. Розрахунок метрик

**Формули для розрахунку:**

- **CPM** = 
    
    ```
    (Spend/Impressions)×1000(Spend/Impressions)×1000
    ```
    
- **CTR** = 
    
    ```
    (Clicks/Impressions)×100%(Clicks/Impressions)×100%
    ```
    
- **CR Clicks to 1st Ep** = 
    
    ```
    (Episode Watch/Clicks)×100%(Episode Watch/Clicks)×100%
    ```
    
- **CR Click to Purchase** = 
    
    ```
    (Purchases/Clicks)×100%(Purchases/Clicks)×100%
    ```
    
- **CPA** = 
    
    ```
    Spend/PurchasesSpend/Purchases
    ```
    
- **Revenue d360** = 
    
    ```
    Purchases×ARPPUd360Purchases×ARPPUd360
    ```
    
- **ROMI d360 (Gross)** = 
    
    ```
    (Revenue d360/Spend)×100%(Revenue d360/Spend)×100%
    ```
    
     (де >100% означає прибутковість)

In digital advertising, an **impression** means **one single time an ad is displayed on a screen**.
